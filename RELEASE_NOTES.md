# Mini QoL v1.0.0

Mini QoL combines **Peddler, Gearwise, Wayfinder and XP Counter** with one compact settings panel, opened from its minimap button or `/mqol`.

- Maps, service icons, gear advice, selling, XP and reputation retain the four components' existing behavior.
- Native NPC dialogue supports number keys for options and reward choices, with optional Space for quest actions. Existing quest icons and other addons' button hooks are preserved.
- Every other addon stays installed separately, with its own settings and minimap icons.

Exit WoW before installing. Back up your settings and move only the standalone `Peddler`, `Gearwise`, `Wayfinder` and `XPCounter` folders out of `Interface/AddOns`, then extract this release there. Keep all other addon folders. The repository's optional installer imports the four components' existing settings and creates backups.

The download contains clean defaults, with no personal settings. Original source credits and licence notices are included.

Validation: exact four-component scope, 58 Lua files compiled, source references, settings, panel navigation and NPC hotkey behavior checked offline. In-game verification remains pending.
